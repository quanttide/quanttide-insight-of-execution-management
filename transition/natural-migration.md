# 迁移宿主，而非断裂心智

切到法人记忆之所以自然，是因为它没有让组织放弃「一个人说了算」，而是把那个「说了算的」从创始人迁到法人/系统。

## 机制

- 大家惯于「**单一主体发号施令**」：一个知道一切、能拍板的人。这是组织默认的心智模型，而不是分布式决策。
- 直接跳到「系统权威 / 多人协作」= **心智硬断裂**：人第一反应是「现在谁说了算」，一个没脸、没体温的系统难以被接受。
- 法人**保住了「单一主体」的形状**：仍是一个主体、一个记忆、一个决策点——只是这个主体是法人，记忆由系统承载。**形状不变，宿主渐换。**
- 迁移因此是连续的：一个老板记+拍板 → 一个法人（系统）记+承载 → 自然人加入法人的单一记忆。全程「单一主体」都在。

## 迁移

- **产品**：周会「老板过一遍」仍是单点视角，只是信息源从「每个人来汇报」变成「系统里读」；员工对「单一权威」的心智不变。
- **演进**：先法人（仍是单一主体，合习惯）→ 后自然人（接入法人记忆，但单一权威仍在，只是制度化）。
- **职责接棒**：在同一「单一主体」框架里，把拍板权下放、由系统承接——而不是突然变成「无人拍板」。

## 边界

- 这不是「去中心化 / 人人平等」，而是「单一主体的**制度化迁移**」——它不代表分布式治理。
- 这一条以「法人记忆被信任」为前提：信任未立，人心仍会回到创始人那个兜底。
