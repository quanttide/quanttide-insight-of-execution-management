# 看清 → 推进 → 提炼

把「让法人记得」拆成三步，每一步都解决一个具体的问题。

## 看清：一眼可见，不必在脑子里数

一个次级法人此刻在做什么、还有什么没做，这是记忆首先要回答的问题。我们用一张二维看板，按状态分成泳道，一个次级法人一块板。

状态彼此分明——没开始、进行中、评审中、已完成。把这些平铺在板面上，法人当前的执行状态就一目了然。用户不必再在记忆里一遍遍地「数」还有几件事、每件到哪了；看一眼板，就知道了。

**看清解决的是「记不记得住」**：让散落的状态有一个可见的、可扫读的载体。

## 推进：改一下就是推进，不必额外记录

看清之后，状态要能随手改变。我们让「推进」成为最轻的动作：拖拽改变状态，即改即存，立即生效。

这里的关键是**去掉中间步骤**。很多工具要你「改状态 + 写一条记录 + 补充说明」，记录这个动作本身很耗注意力。我们让推进这个动作本身就顺带完成记录——拖一下，状态就变了，不必停下来整理。

**推进解决的是「愿不愿意记得」**：把维护成本压到最低，记忆才不会被弃置。

## 提炼（北极星）：把「人记得」转译成「法人记得」

这是三步里唯一让整套东西不像又一款任务工具的功能。它解决的是最根本的问题——**记忆从哪来**。

人不会主动把每件事都记进看板。所以让 AI 从执行日志里蒸馏出「这个法人需要记住的事」，先判断这件事属于哪个次级法人，再写进它的看板。人只做确认。

**提炼解决的是「靠不靠人记得」**：把入口从「人主动记」变成「系统从日志里看见」。这不是优化，而是换了一条路——法人靠系统记得，而不是靠人记得。

正因它是北极星，我们对它格外克制：它目前还标着「规划中」，因为我们更愿意先把看清、推进这两步的地基打牢，再让提炼这个最难、也最有差异化的能力登场。
