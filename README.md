# 量潮执行管理洞察

执行管理领域的洞察档案库，记录**机制、结构洞与差距**——它是「想清楚为什么」的那部分：比意图更接近规律，比路线图更向后看原因，是意图与实现之间的桥梁。

## 项目结构

```
quanttide-insight-of-execution-management/
├── index.md        # 洞察库入口
├── subject/        # 主体：谁该记得（法人记忆）
├── myst.yml        # MyST 文档站配置
├── README.md       # 仓库入口
├── AGENTS.md       # 目录与维护约定
└── .github/workflows/deploy-oss.yml   # 云端连接（发布到 OSS 文档站）
```

## 关联档案

- 意图（我们要什么、为什么）：`data/intention`
- 现状事实与进展：`data/profile`
- 怎么走：`data/roadmap`
